# Plerion Workshop 2026

**https://antkplerion.github.io/Plerion-Workshop26/**

A hands-on workshop that takes you from a fresh Plerion account to running cloud security end to end. Built with Docusaurus, deployed to GitHub Pages.

## Modules

| # | Module | Paths |
|---|--------|-------|
| 00 | **Setup** — Install tools, deploy Bad Cloud, connect your AWS account | All |
| 01 | **See** — Explore your asset inventory and resource relationships | All |
| 02 | **Prioritize** — Risk scores, attack paths, and blast radius | Security Engineer |
| 03 | **Fix** — Remediate via console, Pleri AI, and Terraform | All |
| 04 | **Prove** — Compliance reports and audit evidence | Security Engineer |
| 05 | **Connect Pleri** — MCP integration with Claude Code and your IDE | Platform Engineer |
| 06 | **Work Headless** — API and CLI automation | Platform Engineer |
| 07 | **Teach Pleri** — Custom policies, controls, and org context | Platform Engineer |
| 08 | **Operate** — Alerting, ticketing, and daily security workflows | All |

## Learning Paths

- **Security Engineer** — modules 00, 01, 02, 03, 04, 08
- **Platform Engineer** — modules 00, 01, 05, 06, 07, 08
- **Full workshop** — all nine modules

## Local development

```bash
npm install
npm start
```

The site will be available at `http://localhost:3000/Plerion-Workshop26/`.
